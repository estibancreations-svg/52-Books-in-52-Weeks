# Book Template

Copy this folder structure for each new book once the system is defined.

```
books/book-NN-working-title/
  00-concept.md        # logline, theme, real-world subject the semi-fiction is built on
  01-outline.md         # chapter-by-chapter outline
  02-manuscript/         # draft chapters
  03-edits/               # revision passes
  04-formatting/           # print-layout and e-reader/KDP-layout exports
  README.md               # status, target publish date, links
```

Quality checklist (from the project's Phase 2 standards, to be finalized):

- [ ] Reading level checked at 10th grade
- [ ] Semi-fiction framing consistent with project definition
- [ ] Formatted for physical print
- [ ] Formatted for e-reader/KDP-style output
- [ ] Published to project website
