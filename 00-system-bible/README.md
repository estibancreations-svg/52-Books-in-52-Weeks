# 00 — System Bible

This folder defines the repeatable operating system for **52 Books in 52 Weeks**.

## Active System

The first fully defined content framework is now **True Stories**, introduced 2026-10-05.

It is built for intergenerational stories, remembered conversations, humor, difficult lessons, faith, curiosity, and wisdom passed down through grandparents, elders, family friends, mentors, and community.

### Core production path

**Capture → Meaning → Story → Reflection → Manuscript → Production → Release**

### Weekly rule

A week does not begin with “write 40,000 words.”

A week begins by answering:
1. What is this book trying to give the reader?
2. Why does this story matter now?
3. What lived moments prove the point?
4. What is fact, what is remembered, and what is reconstructed?
5. What is the emotional turn?
6. What does the reader carry away?
7. What is the smallest complete publishable version of this book?

### Quality standard

Each book should be:
- readable at approximately a 10th-grade level unless the specific book calls for a different register,
- emotionally specific rather than generic,
- clear about reconstructed or dramatized material,
- structured around scenes instead of slogans,
- capable of standing alone while contributing to the larger 52-book body,
- edited for continuity, truthfulness, tone, accessibility, and release quality.

See `TRUE-STORIES-SERIES-BIBLE.md` for the first active series architecture.
